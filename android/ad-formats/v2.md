# 네이티브V2

{% hint style="info" %}
SDK 3.5.48부터 새 네이티브 광고 인터페이스를 제공합니다.\
광고 요청은 `CaulyNativeAdLoader`로 하고, 화면 구성은 아래 두 가지 중 하나를 선택합니다.

* **템플릿 방식** : SDK가 제공하는 완성형 레이아웃(`CaulyNativeTemplateView`, SMALL / MEDIUM)에 광고를 연결합니다. 가장 간단합니다.
* **직접 레이아웃 방식** : 매체가 만든 레이아웃을 `CaulyNativeAdView`로 감싸고 각 요소(제목, 본문, CTA, 아이콘, 메인 이미지)를 등록합니다.

두 방식 모두 노출·클릭 보고, "광고" 배지, AdChoices(광고 정보) 아이콘은 SDK가 처리합니다.
{% endhint %}

{% hint style="warning" %}
**기존 네이티브 연동 매체 (3.5.47 이하에서 업데이트하는 경우)**

3.5.48에서 기존 네이티브 클래스의 이름이 변경되었습니다. 기존 코드를 그대로 두면 컴파일 오류가 발생하므로 아래와 같이 클래스명만 바꿔 주세요. 동작은 기존과 같습니다.

| 3.5.47 이하                                                       | 3.5.48 이상                              |
| --------------------------------------------------------------- | -------------------------------------- |
| `CaulyNativeAdView`                                             | `CaulyNativeAdViewLegacy` (Deprecated) |
| `CaulyNativeAdInfoBuilder`                                      | `CaulyNativeAdInfoBuilderLegacy`       |
| `CaulyNativeAdViewListener` 콜백의 `CaulyNativeAdView adView` 파라미터 | `CaulyNativeAdViewLegacy adView`       |

`CaulyNativeAdViewLegacy`는 Deprecated 상태입니다. 신규 연동은 이 페이지의 방식을 사용해 주세요.
{% endhint %}

## 연동 흐름

1. `CaulyNativeAdInfoBuilder`로 광고 요청 정보(`CaulyAdInfo`)를 만듭니다.
2. `CaulyNativeAdLoader`에 요청 정보와 리스너를 설정하고 `request()`를 호출합니다.
3. `onAdLoaded(CaulyNativeAd ad)`에서 받은 광고를 템플릿(`CaulyNativeTemplateView`) 또는 직접 만든 레이아웃(`CaulyNativeAdView`)에 `setNativeAd(ad)`로 연결합니다.
4. 화면을 종료하거나 광고를 교체할 때 `CaulyNativeAd.destroy()`와 뷰의 `destroy()`를 호출합니다.

## 템플릿 방식

{% hint style="info" %}
* **SMALL** : \[아이콘] \[제목 / "광고" 배지 + 본문 1줄] \[CTA]. 메인 이미지가 없습니다. 목록 사이, 화면 하단 고정 영역에 적합합니다.
* **MEDIUM** : 메인 이미지 → \[아이콘] \[제목 / "광고" 배지 + 본문 최대 2줄] → CTA. 피드 중간 카드, 종료 팝업 등에 적합합니다.
* 템플릿은 부모 폭을 채우며, 높이는 내용에 맞게 자동으로 정해집니다.
{% endhint %}

public class NativeTemplateActivity extends AppCompatActivity {

    private CaulyNativeAdLoader adLoader;
    private CaulyNativeAd nativeAd;
    private CaulyNativeTemplateView templateView;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_native_template);

        templateView = findViewById(R.id.native_template);

        // (선택) 템플릿 스타일 지정. 지정하지 않은 항목은 기본값을 사용합니다.
        CaulyNativeTemplateStyle style = new CaulyNativeTemplateStyle.Builder()
                .withMainBackgroundColor(new ColorDrawable(Color.WHITE))
                .withCallToActionBackgroundColor(new ColorDrawable(0xFF4285F4))
                .withCallToActionTypefaceColor(Color.WHITE)
                .build();
        templateView.setStyles(style);

        // 광고 요청 정보
        CaulyAdInfo adInfo = new CaulyNativeAdInfoBuilder("CAULY")   // 발급받은 APP_CODE
                .mediaAspectRatio(CaulyMediaAspectRatio.LANDSCAPE_2_1) // 기본값 2:1
                .build();

        adLoader = new CaulyNativeAdLoader(this);
        adLoader.setAdInfo(adInfo);
        adLoader.setAdListener(new CaulyNativeAdListener() {
            @Override
            public void onAdLoaded(CaulyNativeAd ad) {
                if (isDestroyed()) {
                    ad.destroy();
                    return;
                }
                if (nativeAd != null)
                    nativeAd.destroy();     // 이전 광고 해제
                nativeAd = ad;
                templateView.setNativeAd(ad);
            }

            @Override
            public void onAdFailedToLoad(int errorCode, String errorMessage) {
                // 광고 수신 실패
            }

            @Override
            public void onAdImpression() {
                // 노출 집계 완료 (광고당 1회)
            }

            @Override
            public void onAdClicked() {
                // 광고 클릭
            }
        });
        adLoader.request();
    }

    @Override
    protected void onDestroy() {
        if (adLoader != null)
            adLoader.cancel();
        if (templateView != null)
            templateView.destroy();
        if (nativeAd != null)
            nativeAd.destroy();
        super.onDestroy();
    }
}

### 템플릿 XML 속성

| 속성                                     | 값                                | 설명                                                                                             |
| -------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------- |
| `app:cauly_native_template_type`       | `small` (기본) / `medium`          | 템플릿 종류. 코드에서는 생성자의 `CaulyNativeTemplateType`으로 지정합니다.                                          |
| `app:cauly_native_template_media_mode` | `fixed_ratio` (기본) / `fit_image` | MEDIUM의 메인 이미지 영역 높이 방식. 코드에서는 `setMediaMode(CaulyNativeTemplateMediaMode)`. SMALL에는 영향이 없습니다. |

* `FIXED_RATIO` : 이미지 영역을 가로 2:1로 고정합니다. 광고마다 높이가 일정합니다.
* `FIT_IMAGE` : 받은 이미지 비율로 영역 높이를 정합니다. 광고마다 높이가 달라지며, 1.5:1보다 세로로 길어지지 않습니다(그보다 긴 이미지는 좌우 여백으로 맞춤).

### CaulyNativeTemplateStyle 설정방법

`CaulyNativeTemplateStyle.Builder`로 만들어 `setStyles()`로 적용합니다. AdMob `NativeTemplateStyle`과 같은 항목이며, 글자 크기 단위는 sp입니다.

| 항목             | 적용 대상      | Builder 메서드                                                                                                                    |
| -------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| CallToAction   | CTA 버튼     | `withCallToActionTextTypeface`, `withCallToActionTextSize`, `withCallToActionTypefaceColor`, `withCallToActionBackgroundColor` |
| Primary        | 제목         | `withPrimaryTextTypeface`, `withPrimaryTextSize`, `withPrimaryTextTypefaceColor`, `withPrimaryTextBackgroundColor`             |
| Secondary      | SMALL의 본문  | `withSecondaryTextTypeface`, `withSecondaryTextSize`, `withSecondaryTextTypefaceColor`, `withSecondaryTextBackgroundColor`     |
| Tertiary       | MEDIUM의 본문 | `withTertiaryTextTypeface`, `withTertiaryTextSize`, `withTertiaryTextTypefaceColor`, `withTertiaryTextBackgroundColor`         |
| MainBackground | 템플릿 배경     | `withMainBackgroundColor`                                                                                                      |

{% hint style="info" %}
"광고" 배지의 글자 크기는 정책상 15dp로 고정되며 스타일·리소스로 변경되지 않습니다.
{% endhint %}

## 직접 레이아웃 방식

{% hint style="info" %}
* 레이아웃 최상위를 `com.fsn.cauly.CaulyNativeAdView`로 감싸고, 메인 이미지 영역은 `com.fsn.cauly.CaulyMediaView`를 사용합니다.
* 뷰 ID와 배치는 자유롭게 구성할 수 있습니다.
* 각 요소를 `setXxxView()`로 등록한 뒤 **마지막에** `setNativeAd(ad)`를 호출합니다. SDK가 등록된 뷰에 값을 채웁니다.
* 클릭은 등록한 요소 뷰(제목, 본문, CTA, 아이콘, 메인 이미지)만 인정됩니다. 배경·여백은 클릭되지 않습니다.
{% endhint %}

                if (isDestroyed()) {
                    ad.destroy();

                showNativeAd(ad);

            @Override
            public void onAdFailedToLoad(int errorCode, String errorMessage) {

            }

                // 노출 집계 완료 (광고당 1회)
            }

            @Override
            public void onAdClicked() {
                // 광고 클릭
            }
        });
        adLoader.request();
    }

    private void showNativeAd(CaulyNativeAd ad) {
        releaseNativeAd();
        nativeAd = ad;

        nativeAdView = (CaulyNativeAdView) getLayoutInflater()
                .inflate(R.layout.native_ad_layout, adContainer, false);

        // 1. 요소 뷰 등록
        nativeAdView.setHeadlineView(nativeAdView.findViewById(R.id.ad_headline));
        nativeAdView.setBodyView(nativeAdView.findViewById(R.id.ad_body));
        nativeAdView.setCallToActionView(nativeAdView.findViewById(R.id.ad_cta));
        nativeAdView.setIconView(nativeAdView.findViewById(R.id.ad_icon));
        nativeAdView.setMediaView(nativeAdView.findViewById(R.id.ad_media));
        nativeAdView.setAdBadgeView(nativeAdView.findViewById(R.id.ad_badge)); // 선택

        // 본문은 없을 수 있음
        if (ad.getBody().isEmpty())
            nativeAdView.findViewById(R.id.ad_body).setVisibility(View.GONE);

        // 2. 마지막에 광고 연결
        nativeAdView.setNativeAd(ad);
        adContainer.addView(nativeAdView);
    }

    private void releaseNativeAd() {
        if (nativeAdView != null) {
            nativeAdView.destroy();
            adContainer.removeView(nativeAdView);
            nativeAdView = null;
        }
        if (nativeAd != null) {
            nativeAd.destroy();
            nativeAd = null;
        }
    }

    @Override
    protected void onDestroy() {
        if (adLoader != null)
            adLoader.cancel();
        releaseNativeAd();
        super.onDestroy();
    }
}

### 광고 요소

| 요소      | 등록 메서드                  | 뷰 타입                 | 구분 | 비고                            |
| ------- | ----------------------- | -------------------- | -- | ----------------------------- |
| 제목      | `setHeadlineView()`     | TextView             | 필수 | 값이 항상 제공됩니다.                  |
| CTA     | `setCallToActionView()` | TextView (Button 가능) | 필수 | 값이 없으면 "자세히보기"                |
| 아이콘     | `setIconView()`         | ImageView            | 필수 | 이미지를 받지 못하면 비어 있을 수 있습니다.     |
| 본문      | `setBodyView()`         | TextView             | 권장 | 없으면 빈 문자열("")                 |
| 메인 이미지  | `setMediaView()`        | CaulyMediaView       | 권장 | 없으면 `getMediaContent()`가 null |
| "광고" 배지 | `setAdBadgeView()`      | TextView             | 선택 | 아래 설명 참고                      |

{% hint style="warning" %}
* 필수 요소(제목, CTA, 아이콘)를 등록하지 않으면 경고 로그가 남습니다. 반드시 등록해 주세요.
* **"광고" 배지** : 등록하지 않으면 SDK가 광고 뷰 좌측 상단에 "광고" 배지를 자동으로 붙입니다. 직접 등록하는 경우 글자 크기는 **15dp 이상**으로 지정해 주세요(15dp 미만이면 경고 로그).
* **AdChoices(광고 정보) 아이콘** : SDK가 광고 뷰 우측 상단에 15dp 크기로 자동 부착합니다. 이 영역을 다른 요소로 가리지 마세요.
* 자동 배지와 AdChoices 위치에는 `CaulyNativeAdView`의 padding이 적용됩니다.
{% endhint %}

### CaulyMediaView 표시 규칙

* 정적 이미지만 표시합니다.
* 이미지 비율은 유지되며(가로·세로 같은 배율), 이미지는 가운데 정렬됩니다.
* 높이를 `wrap_content`로 두면 이미지 비율대로 높이가 정해져 잘림·여백 없이 표시됩니다.
* 높이를 고정하면, 영역이 이미지보다 좁은 경우 좌우를 합계 10%까지 잘라내고 남는 부분은 위아래 여백으로, 영역이 넓은 경우 좌우 여백으로 맞춥니다. 여백은 투명합니다.
* 이미지 영역 높이를 직접 계산하려면 `ad.getMediaContent().getAspectRatio()`(가로÷세로)를 사용합니다.

## 노출 / 클릭

* **노출** : 광고 뷰가 화면에 1px 이상 보이는 순간 광고당 1회 보고합니다(화면 꺼짐, 윈도우 비표시 상태 제외). 서버 집계가 완료되면 `onAdImpression()`이 호출됩니다.
* **클릭** : 등록된 요소 뷰를 클릭하면 `onAdClicked()`가 호출되고, 광고 유형에 따라 앱(마켓), 유튜브, Chrome Custom Tab 또는 외부 브라우저로 이동합니다.

{% hint style="warning" %}
- `CaulyNativeAd`는 더 이상 사용하지 않을 때(화면 종료, 새 광고로 교체) 반드시 `destroy()`를 호출해 주세요.
- `CaulyNativeAdView` / `CaulyNativeTemplateView`도 화면 종료 시 `destroy()`로 등록된 뷰와 리스너를 해제해 주세요.
- 요청 중에 화면을 종료하는 경우 `CaulyNativeAdLoader.cancel()`을 호출해 주세요. 이후 콜백은 호출되지 않습니다.
- `CaulyNativeAdLoader.request()`는 메인 스레드에서 호출해야 하며, 1회 요청에 광고 1개를 받습니다. 요청이 진행 중일 때(`isLoading()`이 true) 다시 호출하면 무시됩니다.
- 모든 리스너 콜백은 메인 스레드에서 호출됩니다.
{% endhint %}

```java
@Override
protected void onDestroy() {
    if (adLoader != null)
        adLoader.cancel();
    if (nativeAdView != null)
        nativeAdView.destroy();
    if (nativeAd != null)
        nativeAd.destroy();
    super.onDestroy();
}
```

## CaulyNativeAdInfoBuilder 설정방법

| AdInfo                                  | 설명                                                                                                               |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| AppCode                                 | 발급받은 APP\_CODE (생성자 파라미터)                                                                                        |
| mediaAspectRatio(CaulyMediaAspectRatio) | 메인 이미지 비율. `LANDSCAPE_2_1`(기본, 1200x627 이미지) / `SQUARE_1_1`(500x500 이미지)                                         |
| timeoutSec(int)                         | 광고 요청 타임아웃(초)                                                                                                    |
| userTargetBrowser(String)               | 랜딩에 사용할 브라우저 패키지명                                                                                                |
| region(String) / gcoder(double, double) | 지역 정보. [Cauly 지역정보추가](https://cauly.gitbook.io/cauly/sdk-android/cauly) 참고                                       |
| tagForChildDirectedTreatment(boolean)   | 아동 대상 서비스 취급용 태그 설정. [아동 대상 서비스 취급용 '태그' 설정](https://cauly.gitbook.io/cauly/android/option/child-tag-setting) 참고 |
| gdprConsentAvailable(boolean)           | GDPR 동의 여부                                                                                                       |

{% hint style="info" %}
기존 네이티브의 `layoutID`, `iconImageID`, `adRatio` 등 레이아웃 관련 옵션은 새 Builder에 없습니다. 화면 연결은 `CaulyNativeAdView` 또는 `CaulyNativeTemplateView`에서 합니다.
{% endhint %}

### CaulyNativeAdListener

| 콜백                                                     | 설명                                                                                       |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| `onAdLoaded(CaulyNativeAd ad)`                         | 광고 수신 성공. 아이콘과 메인 이미지는 미리 받아 둔 상태로 전달됩니다. (필수 구현)                                        |
| `onAdFailedToLoad(int errorCode, String errorMessage)` | 광고 수신 실패. [Error Code](https://cauly.gitbook.io/cauly/android/etc/error-code) 참고 (필수 구현) |

| `onAdClicked()`                                        | 등록된 요소 뷰 클릭 시 (선택)                                                                       |

### CaulyNativeAd

| 메서드                 | 설명                                                                          |
| ------------------- | --------------------------------------------------------------------------- |
| `getHeadline()`     | 제목                                                                          |
| `getCallToAction()` | CTA 문구 (없으면 "자세히보기")                                                        |
| `getBody()`         | 본문 (없으면 "")                                                                 |
| `getIcon()`         | 아이콘 이미지(`CaulyNativeAd.Image`: `getDrawable()`, `getUri()`). 없으면 null       |

| `getExtraInfos()`   | 부가 정보. `CaulyExtraInfoUtil`로 단가/과금 유형 조회                                    |
| `destroy()`         | 광고 리소스 해제                                                                   |
